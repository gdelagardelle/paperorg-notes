# Proposed reviewer notes — build 67

Use only after the corresponding candidate has passed device acceptance and has been selected in App Store Connect.

No sign-in or API key is required for the included Free allowance. Accept the privacy notice, choose Free, select a language and note style, then record and stop to receive the transcript and summary. Microphone permission and an internet connection are required for cloud processing.

Free includes 30 transcription minutes per month and up to three minutes per recording. PaperOrg Pro includes 600 minutes per month and up to 180 minutes per recording. Upgrade and Restore Purchases are in Settings. Please review the monthly Pro subscription with this app version.

Continuous recording saves completed audio segments before transcription. Processing may run during recording; the final combined note is prepared after Stop. Captured audio is retained locally when connectivity is interrupted so processing can resume.

This build combines continuous recording with purchase-activation and restore improvements. If Apple has confirmed a purchase while server activation is pending, Settings displays the pending state and Refresh status. The cloud usage balance is displayed after server confirmation.

The privacy notice describes server-managed transcription, summaries and temporary encrypted transcription replay storage. Normal Phone and FaceTime calls are not captured.
